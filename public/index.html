Herramientas útiles, en un clic.

Acorta enlaces y mira cuánta gente los abre, crea códigos QR, genera contraseñas seguras, convierte monedas y unidades, y más. Sin crear cuenta ni instalar nada.

Usar las herramientas ↓

Tu acceso gratuito se activa solo la primera vez que uses una herramienta.

🔗 Acorta un enlace

Convierte una dirección larga en un enlace corto fácil de compartir, y mira cuántas personas lo abren.

🔳 Crea un código QR

Genera la imagen QR de una página web o un texto, lista para imprimir o compartir.

🔐 Genera contraseñas seguras

Contraseñas realmente aleatorias, imposibles de adivinar. Copia la que más te guste.

📏 Convierte unidades

Kilómetros a millas, kilos a libras, grados Celsius a Fahrenheit… elige y convierte.

→

💱 Convierte monedas

Con tasas de cambio reales del día, para unas 160 monedas del mundo.

→

👤 Inventa personas de ejemplo

Nombres, correos y datos ficticios pero realistas. Útiles para plantillas, demos o pruebas.

💳 Revisa un número de tarjeta

Comprueba si un número de tarjeta está bien escrito y de qué marca es. No consulta ningún banco: solo revisa el formato del número.

🆔 Códigos únicos y nombres para enlaces

Genera identificadores únicos, o convierte un título ("¡Mi Página!") en un nombre apto para direcciones web ("mi-pagina").

👩‍💻 ¿Eres desarrollador?

Todo lo de arriba es una API REST: NestJS · Prisma · PostgreSQL, con API keys, rate limiting por plan, errores RFC 7807 y OpenAPI.
